# Student Grade Calculator

## Project Overview

The Student Grade Calculator is a Python program that helps an instructor calculate and analyze student grades for a single course.

The program stores student names and grades in a dictionary, calculates student averages, assigns letter grades, identifies the top-performing student, calculates the overall class average, and counts the number of students who passed.

## Features

* Stores student grades using a Python dictionary.
* Calculates the average grade for each student.
* Assigns letter grades from A to F.
* Finds the student with the highest average.
* Calculates the overall class average.
* Counts students who received a passing grade.
* Displays results in the terminal.

## Grading Scale

| Average  | Letter Grade |
| -------- | ------------ |
| 90-100   | A            |
| 80-89    | B            |
| 70-79    | C            |
| 60-69    | D            |
| Below 60 | F            |

## How to Run

Make sure Python 3 is installed.

Open the project folder in VS Code and open the terminal.

Run:

```text
python grade_calculator.py
```

The program will display each student's average and letter grade, the top performer, the overall class average, and the number of students who passed.
